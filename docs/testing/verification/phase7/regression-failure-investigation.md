## D. Shared root causes

1. **Role landing expectations:** B1–B3, D1–D3, E1, K1–K3, and L1–L3 expected `/dashboard` for internal roles. The accepted route policy uses `/module` for internal roles and `/dashboard` for USER. The browser corrections change only the destination assertion. API denial, hidden-content, and no-protected-read assertions remain.
2. **Conversation header overlap:** G1 and H1–H3 hit the same archived-conversation action obstruction. Playwright reports that the visible/enabled archive control is intercepted by the search field. This is one frontend defect affecting four regressions.
3. **Stale table pagination:** I1 and M3 both reach a previously selected page after returning to an earlier view key. The `useLocalTable` comment states that a changed view resets to page one, but retained paging state restores the former page. This is one frontend defect affecting two regressions.
4. **Client request feedback labels:** M1–M2 and N1–N4 used heading/button/link labels inconsistent with the rendered toast and current controls. The corrected checks still verify success visibility, request behavior, and navigation.
5. **Pricing range mismatch:** P1 isolates a validator/database precision mismatch. The in-memory database confirms the transaction leaves no service or template rows behind despite the 500 response.
