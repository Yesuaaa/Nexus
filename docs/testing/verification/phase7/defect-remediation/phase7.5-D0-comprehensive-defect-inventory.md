## 3. Evidence and classification rules

Historical reproduction means a page report or preserved run reproduced the behavior at its recorded source revision. Current source observation means D0 inspected the present checkout but did not execute the behavior. A historical reproduction is not described as a current runtime pass or failure.

Where a current correction is visible in source but no current regression was executed, the status is PREVIOUSLY FIXED BY DEVELOPMENT — VERIFICATION PENDING or FIX IMPLEMENTED — VERIFICATION PENDING. VERIFIED FIXED is not used in this report.

Severity and priority are copied only where the source report assigned them. “Not assigned” means no severity or priority was established in the authoritative report; D0 does not invent one.

Approval means an administrative/product decision beyond the required page-by-page review. A confirmed defect with an established expected behavior does not require a new business contract. A broken link whose destination requires a new password-reset workflow, a missing real support destination, or conflicting role/status/time rules does require an owner decision.
