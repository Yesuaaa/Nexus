# PG-015 Test Case Specification

Case IDs use `PG-015-F001-`. The A-number identifies the atomic feature. Source keys resolve in [Functional Discovery](PG-015_FUNCTIONAL_DISCOVERY.md), test keys in [Existing Test Baseline](PG-015_EXISTING_TEST_BASELINE.md).

**Disposition** New = NEW TEST REQUIRED. Add = ADDITIONAL ASSERTION REQUIRED. Existing = EXISTING COVERAGE SUFFICIENT. Blocked = CONTRACT CLARIFICATION REQUIRED. Unsupported controls and unrelated mutations are NOT APPLICABLE.

**Environment and dependencies** Unit uses real source imports and synthetic account/time fixtures. Browser means real Next document with controlled Playwright HTTP, synthetic accounts and no Express or database. API means direct Express, real bearer/Prisma/PGlite (F3) except A019-T001/T002 (F4, disposable PostgreSQL). Integration means F1 browser/Next document with intercepted API forwarded to real Express/Prisma/PGlite. B2 and B5 gate timing and allow Express to handle the actual response. Shared settings/messaging can remain synthetic. Full Next.js rewrite coverage is outside the proposed boundary.
