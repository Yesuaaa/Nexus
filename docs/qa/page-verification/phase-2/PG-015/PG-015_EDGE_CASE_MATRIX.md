# PG-015 Edge Case Matrix

See [case specification](PG-015_TEST_CASE_SPECIFICATION.md) for stable IDs and fixtures.

| Boundary or edge                                             | Source-backed expectation and case                                                                                                                                                     |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Missing, revoked or inactive session                         | Portal gates mount, API returns 401. A001-T003, A016-T003, A017-T001.                                                                                                                  |
| Missing read/manage, self, current Head scope                | Portal read differ from manage write. Foreign department 403, mismatched employee/session 404 when applicable. A001-T001, A012, A015-T001, A016-T001, A017-T001.                       |
| Missing department data                                      | Blank selects permitted scope. Directory may be empty for valid unknown ID. Records checks department existence. Unassigned and missing label differ. A004-T002, A015-T002, A016-T002. |
| Fast search and page shrink                                  | Debounced search, latest result, distinct skeleton/status, directory clamp. A003-T002/T003, A005-T001.                                                                                 |
| One/zero/multiple pages, same-date ties                      | Filter before merge and paginate. Empty beyond end preserves total. A008-T001/T002, A016-T002.                                                                                         |
| Same-day, leap, reversed, date boundary, omitted and cleared | UTC defaults, real calendar validation and 366 inclusive cap. Blank date prevents new read. A007-T001/T002/T003 and A016-T002.                                                         |
| Route/view teardown and partial errors                       | Release superseded response, no stale UI for current response key, targeted retries. A009-T001/T002.                                                                                   |
| Page CSV with formula-like, Unicode, commas, quotes          | Page-only and browser-local, literal escaped values, disabled states. A011-T001/T002.                                                                                                  |
| Zero-minute/pending leave and approved overlap               | Only positive current approved leave merges. Keep distinct employee/date rows, retain recorded session state. A008-T001/T003, A018-T002.                                               |
| Open/closed suspension, active unpaid break and overnight    | History and CSV project source status and stored work date. Eligibility requires unfinished suspended session. A010-T003, A011-T001, A012 and A017-T002.                               |
| DST gap and fold, device zone change, whitespace/length      | Resolve selected occurrence, reject ambiguous/missing/invalid timing; trimmed note limits. A013 and A017.                                                                              |
| Failure, cancellation and duplicate submit                   | Idle dismissal has no write. Busy suppresses duplicate/dismissal, error stays editable, committed repeat 409. A014 and A018.                                                           |
| Concurrent closes or employee transfer                       | Independent connections and real locks. Fresh authoritative state after winner commits, atomic close/audit or reject. A019.                                                            |
| Phone/desktop, named controls and keyboard focus             | Shared history menu risk and plain controls evaluated independently. A010-T002, A020.                                                                                                  |
| Unsupported scope                                            | Upload, generic edit/delete, correction submission, report sort and interactive attendance clock are inapplicable to this page.                                                        |
