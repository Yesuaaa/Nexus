## Browser and state

Portal account load precedes mount. Its Account, Preferences, Workspace and Breadcrumb providers wrap the role shell, then AttendanceShell/PageHeader. Anonymous initial route resolves to login; denied USER to dashboard and denied internal accounts to module. Route policy allows active STAFF with headship and active ADMIN/SUPERADMIN with employees:read. It does not confer write authority.

The page starts in Employees with empty search/department, page 1, no selected employee and UTC default dates (browser instant minus 30 days to plus one day). Departments and directory requests run independently. Directory state uses trimmed debounced search, immediate matching preview based on last accepted rows, table busy/status messaging, resource-specific retry, and a footer once current rows settle. Search and department edits reset directory page. Department changes reset records page too. Directory rows show name/employee code and resolved department or named fallback. The eye button opens individual logs and resets their page. The header All logs opens organization/permitted department logs without sending directory text search. Employees returns to prior directory state. Individual logs keep department context as a label and offer All logs to remove employee selection; date edits reset records page. These are local view changes, not deep links.

The records GET runs only in logs view with both dates. The directory hook remains mounted. The active report hides stale rows during pending/error, shows day rows and pagination once settled, and exposes a table-level retry. Aborted or outdated requests cannot settle a new key. Unlike directory pagination, the records hook has no explicit last-page clamping. A blank date prevents the GET; retained data can still surface through the disabled hook, a deferred presentation question. Rows distinguish recorded and approved leave-only dates, UTC-backed dates and policy-zone wall-clock display, net/required minutes, suspension, overnight and review indicators. Shared details show workday/session/break/schedule information and a conditional Reconcile shift button. The correction submission branch of the shared panel belongs to self-service because this page only supplies onReconcile.

Export runs inside the browser, requires a populated settled page, and sends no export API call. It emits only current page rows in matching order with a range/page filename, CRLF records, quotation escaping, and apostrophe prefix for spreadsheet-sensitive initial characters. Closed takes priority over suspended, then active unpaid break, then open. Empty/loading/error disables the button. No upload, generic edit/delete, timer or report sort control exists.

## API, persistence, authorization

The shared bearer middleware returns 401 for invalid, expired, inactive, or deleted sessions and can touch session activity. Department, employee, and records GET handlers delegate to management. It rechecks actor role and current Department.headId. employees:read grants organization scope; a STAFF head gets only the current department. Directory accepts search up to 100 trimmed characters, decimal page 1–100000 and optional valid-shaped department ID. It returns id, fullName, employeeId and departmentId ordered by stored fullName then ID; normalizes email-like names using linked account name or employee code. Empty valid unknown department can yield no directory rows. Records accepts only dates/page/employeeId/departmentId. Day strings must be real ISO dates and span at most 366 inclusive days. Head foreign department is 403. Existing scoped department is checked, and nonexistent department or employee outside effective scope is 404. Report SQL joins by current Employee placement, merges approved positive leave with recorded rows by employee/date, pages ten coalesced keys by work date descending and deterministic tie-breaks, and returns total even when a page is past the end. Reads use RepeatableRead. The response includes summarized days and scoped identity, with canReconcile derived from employees:manage, unfinished suspension, and actor not owning the shift.

POST through the inline attendance router separately validates URL IDs, an exact allowed body, trimmed note length 5–2000 and parseable offset-bearing timestamp. The reconciliation component starts with blank inputs, captures browser timezone and resolves DST gaps/folds; a fold must have a chosen occurrence. It rejects a timezone change at submit, serializes ISO and trimmed note, fences repeat submission with a ref, and keeps fields/busy safeguards until settlement. Success toasts, refreshes current records, and closes. Failure keeps the form and announces the server error. Nonpending cancel/Escape closes without a write. The shared modal uses named Radix dialog and focus restoration, and the history actions use the shared menu. Verify actual keyboard focus chain and narrow/mobile reachability in Phase 2.2.

The write locks initial Department in share mode, Employee in update mode and reviewer User in share mode under ReadCommitted. It rereads actor and placement, denies missing manage grant and self-reconciliation (403), missing employee or parent/session mismatch (404), changed placement or non-open/non-suspended session (409) and future end (400). The confirmed end must follow the session start and open break start and be at least the latest closed break end. The transaction sets audit context, closes an open break and session together, preserves the recorded suspension timestamp, can generate overtime and records approved-leave conflict notification when applicable. Audit triggers and notification side effects share transaction rollback. Session workday/employee foreign key, workday unique employee/date, assignment relationship, and leave request/day relationships constrain persisted data. Repeated successful submission is rejected on the fresh closed state rather than replaying the mutation.
