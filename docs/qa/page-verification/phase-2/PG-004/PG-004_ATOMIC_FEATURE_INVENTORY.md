## Explicit exclusions

- Query-linked request detail (`?request=...`) and type-specific filtering from correction/overtime wrappers are PG-010/PG-012 route contracts. They are not expected on PG-004.
- The page does not request leave data or call `leave-api`.
- The PG-004 correction action cannot manually submit overtime because the default route does not enable `allowOvertime`; automatic overtime rows can still appear and be reviewed in the mixed list.
- Policy settings, audit viewer, time-log records, and attendance clock controls are separate page IDs.
