## Test defects corrected during implementation

- T006 initially used an alert locator that also matched Next.js's route announcer; it now scopes the alert by error text.
- T011's status text initially carried a mojibake dash; the assertion now matches the rendered status text.
- T008 initially used a request date later than the fixture's synthetic clock; the test now advances the fixture clock before submission.
- T014 now Head-verifies the second row because source-backed HR scope hides pending requests when an independent active Head exists. Its history assertion now allows the full session response shape.
- T015 uses a separate existing fixture employee so its later synthetic date cannot make the preserved T016 test's earlier overtime session invalid.

These corrections were test/fixture issues, not application defects. The only remaining confirmed behavior defect is PG-004-D-001; production behavior was left unchanged per scope.
