## Failure triage and resolution

### Confirmed application defect PG-004-D-001 — keyboard-open row actions

- **Case:** T017, nested in T011's browser declaration.
- **Reproduction:** The test focuses `attendance-adjustment-actions-detail-overtime` at the 390 px viewport and presses ArrowDown. The trigger changes to `aria-expanded="true"`, but Playwright cannot find the expected `menuitem` named `View details` after its normal assertion timeout. Pointer opening of the same menu and the detail panel succeeds in T011.
- **Classification:** `FAILED — APPLICATION DEFECT`.
- **Evidence:** final C1 output fails at `getByRole("menuitem", { name: "View details", exact: true }).toBeVisible()`; the test also asserts the trigger's expanded state before that line. The test code does not mock the component and does not mutate application code.
- **Disposition:** retained as a failing approved assertion and recorded as PG-004-D-001. No product fix was made because this task explicitly prohibits production behavior changes.
