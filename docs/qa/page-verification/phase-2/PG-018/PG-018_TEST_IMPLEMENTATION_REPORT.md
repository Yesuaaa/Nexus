## Test and fixture design

Unit imports the actual exported calendar helpers. HTTP tests use the existing startPgliteApp harness with real Express/auth/Prisma and migrated isolated PGlite databases. Synthetic Client A/B each have a separate request, consultation, conversation, meeting, assigned project and shared/private milestones. Internal actors cover ordinary STAFF, current head, project lead (existing fixture), ADMIN and SUPERADMIN. Leave adds employees in separate departments, valid seven-day policy assignments, six statuses, positive/zero minutes and six dates straddling the 42-day interval. All fixture data is synthetic.

New helpers share only isolated seed/snapshot and server lifecycle; they do not reproduce projection algorithms. The Node test wrapper in pg018-browser-server.ts is a fixture lifecycle wrapper, not an eighteenth regression declaration. The integration spawns this offline server, forwards the page's sole calendar endpoint with A's real bearer, independently reads as B, compares domain snapshots, and closes control/API/DB resources through the existing harness. Tokens remain sessionStorage only and are not printed in reports. Snapshot excludes authentication bookkeeping and covers requests, workflows, consultations, meetings, project/workPlan, milestones and leave requests.

Browser tests use actual CalendarPage/Calendar components, synthetic responses and a controlled clock. Pending requests use explicit gates, state barriers, abort controls and finally cleanup. Filters combine locally; month/scope changes issue source-defined queries. Browser event-link activation uses a destination document fixture after checking the real source href, so it verifies keyboard activation and exact URL without pretending to test downstream project/services pages. No external meeting provider is visited.

## Source reconciliation

The authoritative case matrix puts A020-T002 on the API layer. Accordingly the five additions are four browser groups plus one API group, rather than five browser groups mentioned in one plan sentence. No case moved layers and no approved record was added or removed. Staff scope reset can expose only the project/type controls; department/staff filters are organization-only and their clearing is verified in ADMIN/SUPERADMIN expansions. Metrics tests use one deterministic month and assert filter results; they intentionally make no all-fetched-versus-viewed-month product claim.
