## Fixtures and dependencies

- **API/PGlite:** use `apps/api/tests/support/pglite-app.ts` and existing attendance account/policy/time helpers. No live database or PostgreSQL server is needed.
- **Real browser/API:** use the isolated server in `apps/api/tests/support/attendance-browser-server.ts`, `routeAttendanceApi`, existing signed-in staff/admin/head actors, and fixture clock endpoint. Never point these tests at a production or developer database.
- **Mocked browser:** intercept only same-origin `/api/attendance/...`; return contract-shaped current/history JSON. Use delayed responses to exercise loading and pending states. For T023, record method/path/body so cancellation and duplicate-submission assertions are observable.
- **Time zones:** set Playwright `timezoneId` for DST and explicit instant cases. Compare filter request values to visible controls; do not encode an unspecified default timezone contract.
- **Keyboard/focus:** use accessible role/name locators and verify focus after menu/panel dismissal. Shared `RowActionsMenu` has a known PG-004 regression risk; keep page identity distinct in any failure report.
