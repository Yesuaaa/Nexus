## API operation map

| Method | Route                                                                    | Handler                      | Primary effects                                                    |
| ------ | ------------------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------------------ |
| GET    | /api/attendance/adjustments?scope=&page=&search=&type=CORRECTION&status= | management.adjustments       | Scoped, sorted, paginated list and capabilities                    |
| GET    | /api/attendance/adjustments/:adjustmentId                                | management.adjustmentDetail  | Scoped detail and current review capabilities                      |
| POST   | /api/attendance/adjustments                                              | management.requestAdjustment | Idempotent correction request, audit context, pending notification |
| POST   | /api/attendance/adjustments/:adjustmentId/review                         | management.reviewAdjustment  | Verify, approve, or reject under locked current state              |

All four routes inherit requireAuth from the attendance router. No browser/API tests were run during discovery.
