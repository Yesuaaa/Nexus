## Boundaries that are not separate features

- Employee.status and account active/archive state are distinct. This route displays and filters Employee.status but only exposes User login lifecycle controls. T025 covers the state distinction; T039 captures the missing status-surface decision.
- Create, edit, archive and unlink operations include audit/history behavior. A late history failure must roll back the operation; this independent persistence invariant maps to T018-T020 and T029-T030.
- EmployeeCompensation appears in the Phase 1 persistence family but is not queried or edited here. Its restrictive Employee relation matters only to permanent-delete safety.
- No sort/export/upload/download/bulk controls exist. URL/storage restoration is not implemented; page state starts at defaults after fresh navigation/reload.
- PG-022's unpaginated Department Overview C002 is not carried over by analogy. PG-023 has 10 rows per page, while total-count scalability remains the separate PG-023-C003 dependency in T041.
