## Responsive and temporal accounting

The employee page source implements inclusive CSS thresholds at 560px and 1000px. T010 checks 390, 560, 561, 1000 and 1001 CSS pixels in one browser test, giving at/below/above evidence without adding runner registrations. The cases characterize the existing implementation; they do not assert a separate, approved product breakpoint contract. Existing T012 and T025 retain their two-width loops (1440px and 390px), for four existing expanded browser registrations. No PG-022 case or assertion is changed.

For debounced search and requests, use controlled responses and wait for an observed request/render event. Test query replacement by resolving the latest request before a held obsolete response. For pending writes, assert the busy UI before resolving the request; then separately resolve success and failure. No timing claim is inferred from animation duration alone.

## Explicitly inapplicable

PG-023 exposes no upload, export, bulk edit, arbitrary sort, free-form URL state, or direct compensation workflow. Do not invent cases for those surfaces. User lifecycle operations are limited to separately authorized login/profile actions described above. Employee compensation is a related persistence model but is not read or edited by this page.
