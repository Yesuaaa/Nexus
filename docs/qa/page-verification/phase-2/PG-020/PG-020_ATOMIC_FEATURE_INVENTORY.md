## Cross-page boundary

Notification source pages, request/project message bodies, billing records, profile/settings workflows, and module workspaces have their own PG records. PG-020 tests only the link, account role, and shared topbar behavior observable from /dashboard. The dashboard does not create those resources or authorize their destination endpoints.
