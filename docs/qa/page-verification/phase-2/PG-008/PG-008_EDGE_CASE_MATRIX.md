## Environment distinctions

- Mocked Playwright covers rendered controls, request payloads, retries, and client state only.
- API/PGlite covers real Express authorization, validation, response shape, transactions, persistence, and audit rows in isolated in-memory PostgreSQL.
- Browser/PGlite integration covers actual Next.js-to-Express-to-Prisma user workflows; keep it separate from mocked browser evidence.
- PostgreSQL-specific locking and isolation must use a fresh disposable local PostgreSQL database. Never target a configured application database.
