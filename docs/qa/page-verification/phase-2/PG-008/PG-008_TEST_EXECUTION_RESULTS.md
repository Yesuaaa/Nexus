## Initial failures and corrections

- The first web typecheck caught an overly narrow inferred type for the initial query capture. It was changed to an explicit nullable `URL` holder; web typecheck then passed, and the final root typecheck passed for both packages.
- The first API fixture run rejected a cancelled assignment inserted directly because the database trigger correctly forbids that state. The test now creates a valid future assignment and transitions it through the source-supported cancellation field. A later fixture cleanup attempt also conflicted with append-only audit history; it was removed, and the existing overview-count assertion was kept ahead of the added fixture rows. Final focused API and compatibility selections passed.
- The initial mocked browser run had three test-authoring failures: the error locator matched both the route announcer and page error; the keyboard test attempted another control while its menu remained open; and the pending assignment dialog changed its accessible submit name. The test locators/interaction sequence were corrected without changing product code or expected behavior. The final browser run then had 11 passes and the retained A007-T001 application failure.
- The first A006 row projection assertion searched for timezone text as a standalone descendant, but the source renders it as an accessible table cell. It was changed to a cell-role assertion; the create-and-assign workflow then passed twice.
- The 390 px A023 run failure remains uncorrected because it is an existing cross-page fixture assumption outside the policy settings path. The table showed 1–10 of 25 records and did not include the requested row before the test could reach settings. The failure was preserved and is not counted as a PG-008 product defect or passing responsive result.
- The first lint gate reported two `no-useless-assignment` errors for redundant initial `null` values in the concurrency test. The variables are now declared without unused initial values. The final formatter, lint, and typecheck gates passed.

## Failure and blocker classification

1. **A007-T001 / PG-004-D-001 — application defect, reproduced.** In Chromium at 390 px, keyboard ArrowDown changed the shared trigger to `aria-expanded=true`, but the menu item remained absent. Pointer activation opened the same menu. The exact PG-008 case failed in the six-worker suite and in both one-worker repeats. No application code or earlier defect record was changed.
2. **A023-T001 — existing test fixture failure; PG-008 responsive assertions not reached.** The attendance-record table displayed only the first ten of 25 employees while the test expected “Attendance staff” without filtering or paging. This is classified as a test/fixture issue; it is not attributed to policy settings functionality. The broader responsive case was not rewritten.
3. **A012-T003/C001 — contract blocker.** No expectation was added for the all-nonworking-days policy rule.
4. **A025-T001 — environment blocker.** Docker CLI exists but `docker info` cannot reach the Docker Desktop Linux engine. Port 5432 being open did not identify a safe database, so it was not used.
