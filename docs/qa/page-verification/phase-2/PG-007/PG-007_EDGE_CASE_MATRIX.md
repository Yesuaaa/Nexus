- **PG-007-C002 / T010:** whether suspended sessions have a visible status and whether they should contribute to the “Still clocked in” figure.
- PG-006 T025/C001 remains independently blocked for cleared Check-Ins history dates; this discovery does not resolve or rename it.
- PG-006 default history timezone basis and ADMIN-without-Employee 409 behavior remain as documented in the Phase 2 ledger.
