## Considered but inapplicable

The page accepts no user input/body: no form injection, privilege-bearing mutation field, prohibited transition, repeated write, relationship deletion, rollback or actor-attribution surface. Search, upload, download, export, external notification and ownership/parent selectors are absent. The fixed list endpoint ignores query values for permission/projection. Permitted ADMIN/SUPERADMIN data is organization-wide by design; STAFF receives a reduced cross-department directory.
