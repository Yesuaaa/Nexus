Both focused reruns passed; the existing stale-review and typed-link declarations passed in the initial compatibility selection.

The first focused API run exposed invalid synthetic VERIFIED/APPROVED fixture state in the added search/status assertions. Repository migrations completed, but the post-migration identity query returned one account while the test requires zero accounts and `read committed`. Every temporary container was stopped with `--rm`; final Docker inspection showed only the two pre-existing application containers. No database secret is recorded. This case remains blocked and is not counted as passed.
