## Explicitly not applicable

- Sorting and client page-size selection: no sort or page-size control exists on the page.
- Leave request edit or partial-day cancellation: no corresponding control or API exists.
- API overview aggregation: the page does not call `leaveOverview`; direct coverage belongs to the requests overview page.
- An expected “preserve/close selected panel on filter change” outcome: unresolved product contract; see A010-T003.
- Claims that the menu defect is reproduced on PG-011: no PG-011 test was executed. The design only proposes a controlled reproduction case.
