## Explicitly absent or not applicable controls

- No sort control, manual refresh button, client-side page-size selector, or data export control is present in `LeaveRequestsPage`/`LeaveRequestTable`.
- No API endpoint for request editing or day-by-day partial cancellation is present. Cancellation and reversal affect the whole request.
- `leaveOverview` is defined by the API client but not called by this page; do not count it as PG-011 direct feature behavior.
- No separate controller layer exists between Express routes and the leave service.
