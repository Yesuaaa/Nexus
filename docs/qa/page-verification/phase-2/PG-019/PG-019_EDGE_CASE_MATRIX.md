## Deliberately not invented

No file upload/download, attachment proof, rich HTML, payment, workflow approval, client delete/edit menu, employee creation, KPI chart, CSV export or date input exists on the rendered page. Backend reserved PATCH/DELETE remain directly implicated security surfaces; they are not new UI workflows. Directory administrators intentionally inspect all clients and departments; do not invent a per-department admin ownership deny. USER and STAFF must be denied the management surface even for their own known IDs.

No arbitrary rate/throughput, optimistic version field, create idempotency key, snapshot-wide atomicity across separate HTTP calls or stronger mid-flight authorization contract is assumed. Same-email replay is a409 identity conflict, not a replayed201 response. PostgreSQL contention cases establish transaction invariants only. Session lastActiveAt bookkeeping is excluded from domain read-only checks. No stress/DoS/uncontrolled fuzz or production security testing is authorized.

All hypotheses and edge categories reuse the authoritative46 records. No shadow inventory or additional security case total.
