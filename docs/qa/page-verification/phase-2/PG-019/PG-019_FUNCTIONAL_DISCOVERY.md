## HTTP surface and authorization

All seven route/method combinations require `requireAuth` then `clients:read`, derived from current server User.role; fixed catalog grants management roles. POST also clients:create; PATCH/DELETE exact SUPERADMIN. Read-only catalogs exist only as isolated test configuration, not a production per-user grant editor. Browser visibility is not authority. Valid bodies are used for auth tests because global JSON parsing precedes router auth.

## Input and rendering contracts

`parseClientFilters`: trimmed search<=100, status empty/ACTIVE/INACTIVE, four sort keys and asc/desc; page plain decimal safe integer1..100000 (leading zero decimal accepted by regex). Absent defaults; repeated/structured supported parameters invalid; unknown keys ignored. Related IDs ASCII letters/digits/underscore/hyphen length1..80. Encoded malformed IDs are validated after Express decoding. `containsText` escapes %, _ and backslash, so SQL/LIKE-like input is literal. Prisma query objects supply values; no raw SQL request interpolation found in these repositories.

Create/update body must be a non-array object. Name trim length2..100; normalized lowercase email<=254 with dotted domain; contact optional+ then digit plus6..19 digits/spaces/hyphens; isActive boolean. Creation password>=12 JS string units, uppercase/lowercase/digit/special and <=1024 UTF-8 bytes. UI password maxlength256 is a distinct input constraint, not an API limit. Update ignores password/extra fields. No client-supplied role/actor/owner/session/operation fields are writable. Shared Form supplies accessible field errors/focus; API has independent checks.

Rows use name/contact fallbacks, timezone Asia/Manila, escaped text, responsive container layout. Drawer dates tolerate missing/invalid related date as Not scheduled, humanize current enums, show safe overview/profile metadata. `ClientKpiCards` exists in source but is not imported by the current page; no KPI/filter/date editor/export/file action/row dropdown/lifecycle confirmation is rendered. PG-004 shared menu and PG-016 proof dialog defects are preserved historically, not automatically attributed to this direct Eye/SidePanel page.
