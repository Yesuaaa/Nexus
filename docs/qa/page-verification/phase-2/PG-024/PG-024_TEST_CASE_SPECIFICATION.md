# PG-024 Test Case Specification

**Authoritative inventory:** 23 unique cases; 16 NEW, 0 ADDITIONAL ASSERTION, 3 EXISTING-SUFFICIENT, 4 CONTRACT-BLOCKED. **Implementable:** 19 = Browser 15 + Unit 0 + API/PGlite 3 + Integration 1 + PostgreSQL 0.  
**Registration plan:** 16 NEW declarations, 0 existing declaration extensions, 0 additive groups. Contract-blocked cases have no registration until decisions exist. Existing-sufficient records map to unchanged declarations.  
**Locations for later Phase 2.2 only:** new browser declarations in `apps/web/e2e/employees/pg024-overview.spec.ts`; one new PGlite declaration in `apps/api/tests/features/employees/pg024-overview.test.ts`. No tests are authorized or created in this Phase 2.1.

All actors/data must be synthetic. Browser tests use one worker, zero retries, accessible locators and bounded route/event/state gates. PGlite tests use `tests/support/pglite-app.ts`; integration reuse is limited to the prior documented T005 path evidence. Detailed source boundaries are in [functional discovery](PG-024_FUNCTIONAL_DISCOVERY.md); existing declaration semantics and history are in [existing baseline](PG-024_EXISTING_TEST_BASELINE.md).

## Reconciliation

`16 NEW + 0 ADDITIONAL + 3 EXISTING-SUFFICIENT + 4 CONTRACT = 23 unique cases`. `23 - 4 contract = 19 implementable`. Primary layers sum to 19: Browser 15, Unit 0, API/PGlite 3, Integration 1, PostgreSQL 0. There are 16 planned new declarations, 0 existing declaration extensions, 0 additive groups, 6 viewport iterations within T018, and no parameterized runner expansion in the proposed files. T001's six actor variants and T007's data/query matrix are steps within one declaration each.

Every case maps to an atomic feature and to the adversarial assessment. A case mapped to multiple hypotheses is counted once. No execution result is asserted in this design document.
