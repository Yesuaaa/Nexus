## Cross-feature dependencies

- One `loadOverview` operation contains nine concurrent `GET /api/employees` requests and is independent from the `useDepartments` request. The Employee requests share one abort signal; the Department request has another.
- All request paths are reads. API authorization and response population are server concerns; mocked browser cases establish rendering/request orchestration only.
- Each employee count query has a page-local count meaning. Department `memberCount` is an Employee relationship count. No supported requirement says the sum must equal the Employee-directory total.
- The four clarification records and the complete unique-case denominator are controlled in `PG-024_TEST_CASE_SPECIFICATION.md`; do not add uncounted cases to the abuse assessment.
