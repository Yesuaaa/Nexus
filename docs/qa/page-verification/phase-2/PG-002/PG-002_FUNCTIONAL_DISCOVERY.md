## Boundaries

- Source establishes current implementation contracts; the browser/API paths were not executed in this discovery.
- Existing table filters and sorting are server-backed. Search preview is also local over currently loaded rows while a request is pending; it is not evidence that the server has returned all matching accounts.
- The UI omits department sorting and the create dialog omits position/department/team fields. These API-only options are outside page interaction coverage.
- The page does not present account-management history. History is an API persistence invariant and is covered by backend test plans, not a separate page control.
- No application or test source was changed during discovery.
