## Adjacent coverage and skips

- apps/web/e2e/superadmin-attendance.spec.ts:15 has test.skip(live, "Attendance administration uses isolated API fixtures"). The file is skipped in NEXUS_E2E_LIVE mode. Its Workforce Logs test asserts Audit Trail navigation visibility, but it does not exercise /attendance/audit.
- apps/api/tests/support/pglite-app.ts creates a migrated in-memory PGlite database, local socket, Prisma client, and optional Express server; it restores environment values and never targets a live database.
- apps/web/e2e/attendance.spec.ts is serial, starts tests/support/attendance-browser-server.ts via the API test runner in beforeAll, and forwards same-origin browser API calls to that offline fixture. It uses mocked ancillary shell APIs while attendance routes remain real, except tests with narrower page.route intercepts.
- The focused mocked browser declaration B2 intercepts the audit list itself. It is not persistence-backed integration.
- apps/api/tests/jwt-session.test.ts:116 checks that an expired access JWT returns 401 from /auth/me (assertion at 127). This is indirect coverage of shared authentication behavior, not an audit-route assertion.
- No audit-specific standalone unit test for parseAttendanceHistory or the page-private display helpers was found. API cases exercise validation through Express; browser cases exercise display through AttendanceAuditPage.
- No PG-005 assertion was executed during this design-only phase. The Phase 1 test map is an inventory, not a pass report; preserve that distinction.

## Assertion-preservation baseline for Phase 2.2

Before changing any test file, capture the current declarations and assertions at U1/U2/B1/B2/B3/A1/A2/A3/A4/X1/X2. Retain names, route lists, role fixtures, mocked response behavior, PGlite fixture cleanup, assertions, and current skip conditions. Proposed changes are additive: U1 route-matrix assertions, B2 initial-loader assertion, and A1 query/order/projection assertions. New scenarios should use a separate mocked audit spec or a narrowly scoped addition to attendance.spec.ts; do not replace the existing audit tests. Recompare the before/after diff and declaration list at implementation time.
