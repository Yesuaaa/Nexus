## Shared authentication behavior

The shared JWT session suite at apps/api/tests/jwt-session.test.ts:116 covers expired-token rejection and refresh/revocation behavior, but it exercises /auth/me rather than /attendance/audit. T015 adds direct anonymous and USER denial checks on the audit endpoint; do not duplicate the full shared session lifecycle here.

## Non-applicable dimensions

The page has no create, edit, delete, approval, export, download, employee selector, sort control, action-count display, or recordsOnly toggle. Concurrency tests for mutations, duplicate submissions, and transaction rollback belong to the workflow that writes audit events, not this read-only page. T018 preserves one real transfer-to-audit persistence journey without duplicating all writer workflows.
