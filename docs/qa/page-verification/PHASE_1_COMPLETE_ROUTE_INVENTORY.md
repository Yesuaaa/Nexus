## Special files and routing notes

Found under apps/web/src/app:

- Root layout: apps/web/src/app/layout.tsx.
- Portal layout: apps/web/src/app/(portal)/layout.tsx.
- Not-found boundary: apps/web/src/app/not-found.tsx.
- No route handlers, templates, loading boundaries, error boundaries, global error boundary, or parallel-route defaults were found.

The root page renders HomeRedirect, which checks token presence and client-replaces to /dashboard or /login (apps/web/src/app/page.tsx:1-5, apps/web/src/features/auth/components/home-redirect.tsx:1-17). /module/[moduleId] awaits dynamic params, requires a known implemented registry entry, and calls notFound() otherwise (apps/web/src/app/(portal)/module/[moduleId]/page.tsx:1-18).

The source-defined navigation scan found policy-based links, attendance navigation, module registry links, query-mode messaging destinations, dynamic route builders, and redirects. A complete runtime destination set is not determinable statically because destinations depend on account role, permissions, record data, query state, and registry entries. The confirmed orphan destination /forgot-password is detailed in PHASE_1_FINDINGS_AND_LIMITATIONS.md.
